# Плагины для BeholdTV

Плагины обработки (`BPP_*.dll`) для BeholdTV 5.28: измерительные приборы для видео с карты захвата. Видео они не меняют, только показывают его уровни в отдельном окне.

| Плагин | Что показывает |
|---|---|
| [BPP_Waveform](BPP_Waveform/README.md) | Осциллограф яркости (Y) с подсветкой уровней вне 16–235 |
| [BPP_Vectorscope](BPP_Vectorscope/README.md) | Векторскоп Cb/Cr с мишенями цветных полос 75 % / 100 % |

## Сборка и установка

1. Нужен 32-битный MinGW g++ (`-m32`) и заголовки SDK BeholdTV в `../PluginsSDK/PluginsSDK/C++/API` (рядом с этой папкой). Подробно об API и сборке: [../PLUGIN_SDK.md](../PLUGIN_SDK.md).
2. В папке плагина: `sh build.sh`. Скрипт сначала запускает самотест, потом собирает DLL.
3. Закройте BeholdTV и скопируйте DLL в `C:\Program Files (x86)\BeholdTV\Plugins\` (нужны права администратора).
4. Запустите BeholdTV, добавьте плагин в цепочку **Preview** и перезапустите BeholdTV.
5. Окно плагина открывается кнопкой настроек плагина. Настройки и положение окна хранятся в `%APPDATA%\BeholdTV\Plugins\BPP_<имя>.ini`.

У обоих окон одинаковое поведение: размер меняется перетаскиванием краёв, есть кнопка сворачивания, а пункт **Always on top** в системном меню (правый щелчок по заголовку) держит окно поверх всех программ.
